# Third-party notices

ART is an independently designed implementation. It uses general-purpose Rust crates locked by `Cargo.lock`. The release gate rejects missing license declarations and copyleft licenses outside the approved policy.

Machine-readable artifacts:

- `docs/artifacts/third-party-licenses.json`
- `docs/artifacts/art-0.1.0-rc.1.spdx.json`
