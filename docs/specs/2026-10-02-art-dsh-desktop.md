# ART desktop host integration contract

Adapt the existing DSH stdio integration to the installed official desktop 0.2.0-rc.2. The user authorized independent research, implementation and acceptance, stopping before publication.

Provide `art integration dsh --desktop` as a read-only JSON preview of a self-contained export. `--apply --output <new-directory>` creates a private directory containing an MCP patch, the DSH skill, and its private-memory value-standard reference. Existing destinations, missing profiles and invalid identities fail without replacement. Existing non-desktop CLI behavior stays compatible. Desktop exports contain literal absolute executable/home paths so Finder launches need no shell environment. Never modify host configuration implicitly or install another host runtime.

Installation uses the Electron-owned desktop profile and its bundled MCP client. Merge a patch into the existing YAML array; do not append to a standalone `[]`, overwrite unrelated entries or use the reserved desktop profile through CLI. Skills include their relative references after installation. Governance stays ART page-first, default-off, and Agent-bound.

Acceptance: failing-then-passing CLI contracts, release gate, release binary and packaged artifacts; isolated real installed desktop sessions proving bound health, skill loading, explicit memory capture/read/recall, secondary-Agent private isolation, shared visibility, page rendering and lifecycle closure. Use task-owned ART/DSH/browser storage and synthetic evidence only. Any blocked real-host journey blocks ready-for-release status. Preserve final evidence and deliverables; stop task-owned processes and retain recoverable residue separately. No tag, public release, merge or formal shared ART publication is authorized.

The candidate version is 0.3.7. A pre-existing release performance failure required connection reuse during verified shared candidate hydration; keep the 150 ms threshold and all ranking/hash/revocation behavior.
