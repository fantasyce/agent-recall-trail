# Maintainer outreach

Subject: ART v0.1.0 — a review-gated memory and knowledge runtime for Codex and DSH

We have released ART, an Apache-2.0 local runtime that keeps each Agent's private memory separate and shares only human-reviewed Knowledge Editions. It is not a transcript store and does not let an Agent approve its own knowledge. We would value a design review of the MCP boundary, provenance locks, and operator workflow before discussing any integration.
