# Maintainer outreach

Subject: ART v0.1.1 — a review-gated memory and knowledge runtime for Codex and DSH

We have released ART v0.1.1, an Apache-2.0 local runtime that keeps each Agent's private memory separate and shares only human-reviewed Knowledge Editions. It is not a transcript store and does not let an Agent approve its own knowledge. The release adds encrypted Git-backed backup and fresh-home disaster recovery for the governed Knowledge Vault. We would value a design review of the MCP boundary, provenance locks, recovery model, and operator workflow before discussing any integration.
