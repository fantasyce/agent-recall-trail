Subject: ART v0.3.5 — exact review for governed Agent knowledge

We have released ART v0.3.5, an Apache-2.0 local runtime that keeps each
Agent's private memory separate and shares only reviewed Knowledge Editions.
The release adds an exact-revision governance workspace, visible decision and
publication states, persistent default-off delegated governance, and verified
Codex and DSH host acceptance. ART is not a transcript store. Human governance
remains the default; delegated actions are explicitly enabled and distinctly
labeled. We welcome sanitized reviews of the MCP integration, provenance,
recovery, retrieval, and governance boundaries.
