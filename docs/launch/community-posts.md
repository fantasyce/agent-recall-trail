# Community launch copy

## Short post

ART v0.1.0 is open source: private Recall Trails for each coding Agent, plus human-reviewed shared Knowledge Editions. Local Rust runtime, Codex + DSH, no cloud account, no autonomous publication. https://github.com/fantasyce/agent-recall-trail

## Technical community post

We built ART around a hard boundary: memory is private to one Agent; knowledge is an immutable, human-reviewed artifact. It is not a transcript store. The first stable release supports Codex and DSH through six bounded stdio MCP tools, SQLite/FTS5, deterministic Markdown migration receipts, and Apache-2.0 source. Feedback on provenance, isolation, and review semantics is welcome.
