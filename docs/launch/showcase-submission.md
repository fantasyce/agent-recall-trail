# Showcase submission

**Agent Recall Trail (ART)** is a local-first memory and governed-knowledge runtime for coding Agents. Each Agent receives a physically separate private vault. Reusable material becomes cross-Agent knowledge only after a human-reviewed, immutable publication step. ART supports Codex and DSH over stdio MCP with progressive route/recall/read, lexical default, governed full scan, and optional provider-neutral semantic/hybrid retrieval. It is not a transcript store and ships under Apache-2.0.
