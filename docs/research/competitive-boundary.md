# Competitive boundary

ART uses public market research only to understand common user needs. The implementation is clean-room and zero-copy: no competitor source, schema, tests, prompt text, directory design, proprietary names, or composed workflow is consulted or reproduced. The architecture is derived from ART's own invariants: physical per-Agent Vaults, source-anchored private memory, append-only assurance, human-reviewed immutable Knowledge Editions, and temporary Recall Bundles.
